# 🧰 Extensões e Ferramentas Recomendadas

## 🟣 Para o Obsidian

### Essenciais (para o nosso workflow)
| Extensão | Porquê |
|---|---|
| **Excalidraw** | Desenhar diagramas, fluxos, wireframes à mão livre dentro do Obsidian |
| **Kanban** | Quadro de tarefas estilo Trello dentro da vault |
| **Dataview** | Consultas tipo SQL nas notas (ex: listar todos os bugs por gravidade) |
| **Graph Analysis** | Ver relações entre notas (já vem incluído) |

### Úteis
| Extensão | Porquê |
|---|---|
| **Tag Wrangler** | Gerir tags facilmente |
| **Folder Notes** | Clicar numa pasta abre uma nota |
| **Advanced Tables** | Formatar tabelas no markdown |
| **Todoist Plugin** | Se quiseres sincronizar tasks com o telemóvel |

---

## 💙 Para o VSCode

### Essenciais
| Extensão | Porquê |
|---|---|
| **Python** (ms-python) | Linting, autocomplete, debug |
| **Pylance** | Type checking para Python |
| **ESLint** | Erros de TypeScript em tempo real |
| **Prettier** | Formatador de código automático |
| **Expo Tools** | Atalhos específicos para Expo |
| **Git Graph** | Visualizar commits e branches |

### Úteis para o Besord
| Extensão | Porquê |
|---|---|
| **MongoDB for VS Code** | Explorar a base de dados sem sair do VSCode |
| **REST Client** | Testar endpoints sem sair do editor (ficheiros `.http`) |
| **YAML** | Suporte para `render.yaml` |
| **GitLens** | Ver quem escreveu cada linha de código |
| **Error Lens** | Mostra erros inline no código |
| **Thunder Client** | Alternativa ao Postman dentro do VSCode |
| **Markdown Preview Enhanced** | Preview melhorado de markdown |

---

## 🐚 Para o Terminal

| Ferramenta | Instalação | Uso |
|---|---|---|
| **htop** | `sudo apt install htop` | Monitorizar CPU/RAM |
| **bat** | `sudo apt install bat` | `cat` com syntax highlighting |
| **fzf** | `sudo apt install fzf` | Pesquisa fuzzy no terminal |
| **httpie** | `pip install httpie` | `http localhost:8000/api/posts` (mais legível que curl) |

---

## 🎯 Setup Rápido das Extensões VSCode

Copia e cola no terminal:

```bash
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
code --install-extension bycedric.vscode-expo
code --install-extension mhutchie.git-graph
code --install-extension mongodb.mongodb-vscode
code --install-extension humao.rest-client
code --install-extension redhat.vscode-yaml
code --install-extension eamodio.gitlens
code --install-extension usernamehw.errorlens
code --install-extension rangav.vscode-thunder-client
code --install-extension yzhang.markdown-all-in-one
```
